# 合理差异化决策框架

## 目标与输入

判断应修复熟悉的购买表达，还是建立受控记忆点。输入当前问题、产品画像、受众 / 活动决策、美国站同类型 KT 板灯牌参考和获授权经验。

## D1：评估市场依据

- 对齐数字 / 字母、结构、尺寸、单件 / 组合、价位、活动和图片角色。
- 样本按 Listing 去重；记录来源、日期、出现次数 / 有效样本数与选择偏差。
- TOP / 销量须有独立依据，单张参考只能支持局部借鉴。
- 不可比或过期样本不用于直接定共识；没有时间序列只判断样本模式，不宣称趋势变化。
- 区分“观察到常见”“购买信号假设”“特定条件下实测有效”。

## D2：分类设计元素

| 分类 | 判断标准 | 决策 |
| --- | --- | --- |
| 必须保留 | 产品身份、真实尺度、售卖数量、KT 板结构 / 外观、灯点 / 灯色、适用官方要求 | 不参与创新权衡，错误先修复 |
| 市场主流 | 可比样本中有据的熟悉表达，对当前购买任务有解释价值 | 优先保持，说明依据与适用范围 |
| 可创新 | 不破坏上述条件，且能解释真实优势或改善任务表达 | 形成待验证突破点 |
| 无依据 / 不适用 | 无可观察依据，或所需事实与功能不成立 | 排除或暂定，不写成确定策略 |

出现频繁不足以证明必须保留；每个主流元素还需解释它如何帮助字符识别、尺度理解、亮灯信任或组合判断。

## D3：选择路线

```text
关键事实错误 / 已核实规则冲突？
  是 → 先纠正，再判断设计路线
  否 → 基础识别与购买信息有缺口？
          是 → 有据的突破机会存在？
                  是 → repair_then_differentiate
                  否 → mainstream_repair
          否 → 市场与产品依据足够？
                  否 → insufficient_evidence
                  是 → 有明确用户价值且可验证的突破？
                          是 → controlled_differentiation
                          否 → 保持稳健主流方案，不强造突破
```

证据不足不阻塞明确的事实纠正或基础诊断；不能用“主流修复”冒充已完成市场判断。偏离主流也不自动判错，须分析影响机制。

## D4：80/20 策略约束

- 80% 符合市场主流审美、20% 形成差异化优势是设计启发式，不计算面积、像素、图片数量或效果贡献。
- 主体购买信息保持熟悉，在少量有价值维度探索表达；不机械填满突破比例。
- 允许突破表达方式，不改变字符、尺寸、材质、数量、灯点、真实灯色或未确认功能。
- 主图创新受官方要求限制；活动布景和品牌文案不能因此自动进入主图。
- 无合理突破机会可不创新；未实测只称差异化假设。

## D5：验证与输出

每项策略记录 `S-ID`、路线、问题 / 证据、必须保留项、主流表达、可突破项、用户价值、机制假设、风险、成本及验收 / 实验方法。

成图检查验证身份保真、识别与表达；CTR / CVR 需实际可比反馈。无数据不得声称成功或提升幅度。

输出 `strategy_decision` 交给 [优先级框架](visual-priority-framework.md)，并贯穿修改方案和 Prompt。冲突时产品事实与官方要求优先。
