# 产品分析决策框架

## 目标与范围

为 Amazon US KT 板数字 / 字母发光灯牌建立可靠产品画像，先判断事实，再决定视觉表达。开放框架仅在结构证实时适用。此框架不判断其他产品类别。

依据：实拍、SKU、实测资料、装配说明和用户提供的来源；视觉印象不能代替尺寸、材质或性能证明。

## 输入

- 产品 / SKU、具体字符、顺序、单件或组合、包装数量。
- 正面、侧面、背面、亮灯 / 未亮灯及装配素材。
- 材质、字符宽高、板厚、支撑、灯点、灯色、供电及已确认功能。
- 当前图片角色、来源、用户反馈和信息冲突。

## 判断顺序与分支

| 节点 | 判断问题 | 条件与行动 | 输出 |
| --- | --- | --- | --- |
| P1 范围 | 是否为美国站 KT 板灯牌？ | 已证实：继续；未知：整理可见信息，范围暂定；明确不符：结束本 Skill 的品类策划 | 范围状态、依据 |
| P2 类型 | 数字还是字母？单件还是组合？ | 按 SKU 锁定字符、方向、顺序和件数；结构标签另行确认，不从活动用途推定套装 | 产品身份锁定表 |
| P3 结构 | 普通或开放框架？装配和支撑是否明确？ | 多视角及说明支持才定型；缺背面或侧面则保留未知，不生成隐蔽结构 | 结构事实与盲区 |
| P4 尺寸 | 高度、宽度、板厚及组合跨度是否有依据？ | 分开产品、包装、支撑和组合尺寸；有资料才标值，无资料不由人物反推 | 尺度约束、待测量项 |
| P5 材质 | 板体与边缘能否保持真实 KT 板外观？ | 资料与图像一致：锁定外观；冲突：待核实，不以修图掩盖 | 材质约束 |
| P6 灯光 | 灯点、灯色、亮灯条件和功能是否确认？ | 亮度 / 色温数值需证明；照片只能支持可见表现；不公平曝光不作优劣依据 | 光效事实与限制 |
| P7 使用 | 安装、供电、环境与包装内容是否支持计划表达？ | 已证实才展示功能；未知条件不暗示防水、户外或安全能力 | 使用与售卖边界 |

顺序为 P1 → P2 → P3 → P4 → P5 → P6 → P7。关键事实冲突暂停受影响的规格文案和 Prompt；不相关的图片观察继续。

## 设计判断

- 身份优先于氛围：字形、件数和包装内容未锁定，不进入可执行组合制作。
- 尺度优先于“大型感”：分别判断主体占画面比例和真实产品高度，禁止改变产品宽高或人物比例。
- 结构优先于整洁：支撑、接缝和灯座若属于真实产品，不为美化移除。
- 可信发光优先于更亮：保留灯点和轮廓，环境照明不超出证据。
- 可见部位保真不等于整体性能通过；未知隐藏结构仍标记无法判断。

## 输出与完成门槛

输出 `product_profile`：范围状态、类型 / SKU、字符与数量、结构、尺度、材质、光效、使用边界、证据 ID、冲突和缺失项。

字段状态：已确认 / 用户陈述 / 可观察 / 未知 / 冲突。进入成品卖点和规格 Prompt 的关键字段必须已确认；其余只进入显式标记的草案。

下游：交给 [受众选择](audience-selection-framework.md)与[场景选择](occasion-selection-framework.md)。产品事实变化时，重新检查受影响的策略、方案和 Prompt。
