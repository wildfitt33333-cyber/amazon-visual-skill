# 视觉优化优先级决策框架

## 目标与输入

把美国站 KT 板灯牌问题变为有依据、可执行的制作任务。输入问题 / 区域证据、产品事实、图片角色、市场策略、素材、模型能力、成本和任务依赖。

## V1：先判断证据与任务状态

- 明确观察或确认事实支持问题：进入任务排序。
- 关键事实冲突：先建立核实任务，受影响制作 `blocked`，不补造答案。
- 官方规则未核实：列为待核实，不直接判违规。
- 已明确缺陷但暂缺素材：保留其重要级别，并标记受阻。
- 未发现问题：允许保持，不为填表创建改动。

任务状态为 `ready / draft / blocked / not_applicable`；与优先级分开，受阻任务不会因此自动降级。

## V2：确定优先级

| 级别 | 条件 | 灯牌检查对象 |
| --- | --- | --- |
| P0 必须纠正 | 已证实的事实错误、误导售卖内容或已核实规则冲突 | 字符 / 顺序、虚增组合和件数、虚假尺寸 / 材质 / 功能、适用主图规则 |
| P1 优先修复 | 重要识别、购买理解、可读性或真实感问题 | 字形遮挡、灯点过曝、尺寸不清、包装边界难懂、支撑与环境明显不合理 |
| P2 后续迭代 | 基础满足后的细节、风格或探索 | 场景层次、辅图一致性、受控差异化试验 |

按具体证据判级，不能把所有光影或场景问题一律定为 P0。年龄与活动标签不影响优先级，影响的是实际购买任务。

## V3：区分图片目标

- 搜索主图优先字符识别、真实售卖主体、缩略图与官方要求；目标假设主要关联 CTR。
- 辅图优先尺寸、灯光效果、组合数量、装配和活动用途理解；目标假设主要关联详情页决策。
- 图片组优先信息覆盖、顺序和事实一致，避免重复场景挤掉关键说明。
- 不因某张图更漂亮就优先；每项说明用户会少一个什么疑问。

## V4：同级排序与依赖

1. 先检查证据强度、影响对象和影响范围，不用虚构的收益百分比排序。
2. 同级中优先处理核心图片与阻塞后续制作的事实 / 素材任务。
3. 在影响相近时考虑成本、可逆性、素材可得性和验证难度。
4. 依赖任务先做，保留两种顺序：重要性顺序与可执行制作顺序。
5. 证据或资源改变后重新排序，记录理由，不默默删掉重要受阻问题。

不使用未经验证的综合分数假装精确收益；不同维度无法比较时说明取舍。

## V5：选择制作方式

| 判断 | 方式与限制 |
| --- | --- |
| 源图可靠、局部问题明确，工具支持保真编辑 | 局部编辑；明确蒙版与不改区域 |
| 产品实拍可靠，需要更换活动环境 | 合成；核对尺度、地面、照明和装饰边界 |
| 结构 / 字符严重失真或需验证真实发光 | 重拍或补素材，不能只靠生成认证性能 |
| 图片任务 / 顺序本身不合理 | 重做 Brief / 组图结构，再生成制作 Prompt |
| 必需事实、素材或能力不足 | 标记草案 / 受阻，继续独立任务 |

## 输出与验收

输出任务清单：任务 ID、图号、问题 / 策略 ID、P0 / P1 / P2、理由、证据、方式、状态、成本、依赖、保留 / 调整项、验收条件。

验收需具体检查字符、数量、尺度、灯点、材质或信息任务；“更高级”不能作为标准。新品沿用本体系排序制作与补素材任务，不生成不存在的旧图缺陷。
