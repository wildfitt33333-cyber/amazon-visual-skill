# 受众选择决策框架

## 目标

确定谁购买、谁布置、谁参与活动，以及需要解决什么购买顾虑。仅服务美国站 KT 板灯牌；年龄是用户提供的场景条件，不是审美或心理结论。

## 输入

产品画像、活动目标、用户明确的人群 / 年龄信息、购买用途、主题约束、评价 / 退货 / 调研反馈及来源。没有年龄资料时保留未知，不从照片、名字或字符推断年龄。

## 判断顺序

### A1：分离购买角色与出镜角色

- 购买者、布置者、庆祝对象和合影参与者分别记录，不假设为同一个人。
- 未指定人物时先判断是否需要人物解释用途或尺度；不为了填画像而强行加人。
- 儿童相关活动不将儿童设为安装者或电源操作者，也不暗示玩具属性。

### A2：选择受众标签

| 条件 | 选择 | 限制 |
| --- | --- | --- |
| 用户明确儿童相关活动 | kids | 组织成年人购买与儿童活动需求，不推断安全认证 |
| 用户明确青少年相关活动 | teen | 主题由输入决定，不自动使用特定配色 |
| 用户明确成人相关活动 | adult | 不预设婚姻状态、风格或购买能力 |
| 用户明确长者相关活动 | senior | 不推断健康、操作能力或审美 |
| 信息混合或未提供 | 多角色 / 未确定 | 不强行归类，使用任务和顾虑分析 |

不建立未经业务确认的年龄区间阈值。具体年龄仅用于已确认的生日数字或用户要求，不成为刻板偏好依据。

### A3：判断购买心理与证据等级

按信息来源提炼需求：

- 功能理解：字符 / 组合是否正确、灯光是否符合活动、尺寸是否适合位置。
- 不确定性：包装数量、装配与供电是否清楚、真实效果与图片是否一致。
- 活动表达：灯牌是否适合已指定主题、合影或现场布置。

明确反馈可支持“用户提出的顾虑”；评论样本必须记录范围，不推广到全部美国买家。没有反馈时仅输出需求假设，不将年龄直接映射到焦虑、身份或偏好。

### A4：将需求转换为图片任务

每项需求关联一个可回答的购买问题、所需事实、适合的图片角色与验收方法。事实缺失优先补证据，不能用漂亮场景替代说明。

### A5：校验是否需要调整

画像与产品能力或活动输入冲突时修订画像；多角色需求不同则保留差异，不平均成一个虚构典型用户。用户更正优先于模型假设。

## 输出与完成门槛

输出 `audience_decision`：角色、输入支持的受众标签、使用任务、购买动机 / 顾虑、来源、假设、图片任务、限制和待确认项。

只有假设时标记“受众待验证”，可继续条件策划；缺年龄不阻塞数字无关的分析。不得给出未经证实的美国人群偏好或转化预测。
