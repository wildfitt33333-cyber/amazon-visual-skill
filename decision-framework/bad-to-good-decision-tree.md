# KT 板灯牌差转优决策树

## 目标与输入

把现有图片、参考、产品信息与反馈转为诊断、路线、任务、Prompt 和验收。范围限定 Amazon US KT 板数字 / 字母灯牌；本文件定义判断体系，不含案例。

## 总体决策流程

```text
B1 范围与产品身份
 ├─ 明确超范围 → 说明边界，结束该品类策划
 ├─ 关键事实未知 / 冲突 → 暂定范围，锁定受阻项，继续可观察分析
 └─ 已确认 → B2

B2 当前图片能否实际查看？
 ├─ 否 → 请求可访问素材；产品 / 反馈整理继续，诊断未完成
 └─ 是 → 独立观察逐图及图片组 → B3

B3 是否有已证实事实错误或规则冲突？
 ├─ 是 → 记录 P0 和核对依据；受影响制作先纠错
 └─ 否 / 未核实 → 保留问题或核实任务，不预判违规
 然后 → B4

B4 参考是否可访问且可比？
 ├─ 无参考 / 无法查看 → 差距与市场判断缺失，继续当前图修复
 ├─ 不可比 / 样本有限 → 只做适用部分的局部借鉴，记录排除理由
 └─ 可比 → 独立分析、功能对齐、去重、市场模式与购买信号假设
 然后 → B5

B5 受众与活动有输入依据且产品支持？
 ├─ 是 → 明确图片任务与场景约束
 └─ 否 → 条件候选 / 待补信息；不新增字符、年龄、年份或功能
 然后 → B6

B6 基础识别 / 购买信息是否缺失？
 ├─ 是且有突破依据 → 先修复后差异化
 ├─ 是且无突破依据 → 修复基础；主流结论按市场证据限定
 ├─ 否且有价值、可验证的突破 → 受控差异化
 ├─ 否且无需突破 → 保持稳健方案
 └─ 市场 / 产品依据不足 → 证据不足路线，只交付可支持部分
 然后 → B7

B7 优先级、依赖和制作条件
 → 分开重要性与执行顺序
 → 选择局部编辑 / 合成 / 重拍 / 重做
 ├─ 必需条件不足 → Prompt 草案 / 受阻；完成其他任务
 └─ 条件齐备 → 逐任务方案与英文 Prompt
 然后 → B8

B8 验收与反馈
 → 方案完整性检查
 ├─ 无实际改图 → 成图验收待执行
 └─ 有实际改图 → 查看并对照产品事实与标准
 ├─ 无可比经营数据 → 业务效果未验证
 └─ 有数据 → 校验版本、口径、窗口、分流与混杂因素
 → 交付结果、限制、待补项；有授权证据时形成经验候选
```

## 各节点的专业判断依据

| 节点 | 使用框架 | 必须记录 |
| --- | --- | --- |
| B1 | [产品分析](product-analysis-framework.md) | SKU、结构、尺度、材质、灯光、范围状态 |
| B2–B3 | 产品分析与知识库视觉规则 | 图片 / 区域、观察、证据、影响假设和限制 |
| B4 | [差异化](differentiation-framework.md)的市场证据检查 | 参考范围、TOP 依据、可比性、样本模式 |
| B5 | [受众](audience-selection-framework.md)、[场景](occasion-selection-framework.md) | 购买角色、顾虑、活动、字符与使用条件 |
| B6 | 差异化框架 | 原因链、路线、必须保留、主流与可突破项 |
| B7 | [优先级](visual-priority-framework.md) | P0 / P1 / P2、成本、依赖、方式、状态 |
| B8 | [验收模板](../skills/amazon-visual-optimization/templates/acceptance-template.md) | 实际检查与未执行检查、效果解释范围 |

## 回退与修订规则

- 产品资料变化 → 回到 B1，重新检查受影响的组合、场景和 Prompt。
- 新参考改变市场依据 → 回到 B4，修订策略，保留旧结论与版本。
- 成图失真 → 回到 B7，调整制作方式，不降低保真验收要求。
- 真实反馈与策略预期不符 → 检查数据有效性与其他因素，再修订假设；不能隐藏失败。
- 阻塞某个节点不意味着所有分析停止；交付应逐项说明完成、草案、受阻或不适用。

## 固定交付与结束条件

使用 [差转优报告模板](../skills/amazon-visual-optimization/templates/bad-to-good-report-template.md)，保留当前问题、参考差距、优先级、修改方案和 AI Prompt，并增加市场依据、原因链、路线与验收。

结束条件是所有可执行节点已完成，缺失项明确且不被伪造；没有改图或实验时，不能称为已实现“差转优”或已提升 CTR / CVR。知识库和决策层提供方法，不能代替当前项目证据。
