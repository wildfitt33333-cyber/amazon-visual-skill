# 活动场景选择决策框架

## 目标与输入

为美国站 KT 板灯牌选择能解释实际用途的场景。输入产品身份 / 尺寸 / 使用条件、受众需求、具体活动、数字 / 词组 / 年份、素材与品牌约束。

活动不是新品类；装饰只服务灯牌。没有指定活动时，可以提出待确认的候选用途，不自动把候选写成已确认项目。

## 决策流程

1. **确定图片任务**：主图遵循适用官方要求，不自动加生活背景；辅图根据用途、尺度或组合理解选择场景。
2. **核对用途依据**：优先使用用户明确活动；其次使用有来源的反馈或产品定位；纯推断标记候选。
3. **核对字符能力**：实际 SKU 是否支持所需数字 / 字母与数量？不支持则排除该具体表达，不新增字符。
4. **核对空间能力**：真实尺寸、支撑、供电和环境条件是否支持摆放？未知时不生成暗示能力的画面。
5. **判断沟通价值**：场景是否解决用途或尺寸问题？只有装饰效果时降低优先级。
6. **选择主要场景**：比较证据、需求匹配、素材可得性和制作成本；保留备选及排除理由。

## 场景选择表

| 活动 | 选择条件 | 必须核对 | 不允许默认 |
| --- | --- | --- | --- |
| Birthday | 已确认生日 / 纪念数字或字符用途 | 数字、順序、件数、人物尺度 | 年龄、主题色、整套随附 |
| Wedding | 已确认婚礼字符或日期需求 | 词组 / 缩写、摆放、组合边界 | 完整套装、特定婚礼审美、户外能力 |
| Proposal | 已确认求婚表达且 SKU 能实现 | 字符、人物动作、低光可读性 | 额外字母、供电 / 遥控功能 |
| Graduation | 已确认毕业目标 | 项目年份、组合数量、授权主题 | 当前年份、统一校色偏好 |
| Baby Shower | 已确认迎婴活动与字符需求 | 词组、灯色、用途边界 | 婴儿性别配色、玩具或睡眠用途 |
| Holiday Party | 已确认具体节日 | 词组 / 年份、灯色、环境支持 | 变色功能、雨雪或防水能力 |

## 取舍与异常处理

- 多场景只有在真实用途支持且各有信息任务时保留，不为丰富图片数量堆场景。
- 场景需要不存在的 SKU 或未知功能：标记不适用或受阻，提出补资料而非修改产品。
- 没有场地尺寸时不能断言“适合任何空间”；采用不夸大尺度的条件方案。
- 人物和布景挡住字符：先调整摆放或机位，不改字形；环境不能替代产品辨识。
- 所有候选缺乏依据时，先输出产品 / 规格策划，活动方案暂定。

## 输出与完成门槛

输出 `occasion_decision`：主要 / 备选活动、依据、具体字符、使用任务、空间关系、人物与装饰角色、排除项、风险、所需素材、验收条件。

进入成品场景 Prompt 前，字符、组合和关键使用条件必须明确。尚无条件的场景只能是草案。
