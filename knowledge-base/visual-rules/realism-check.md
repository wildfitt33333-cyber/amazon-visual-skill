# KT 板灯牌：真实感检查

## 检查依据

以实拍、SKU 和装配说明为准。每项记录图片 / 区域、事实来源与“通过 / 未通过 / 待执行 / 无法判断 / 不适用”，不能凭生成图认证功能。

## 检查清单

| 维度 | 灯牌专项问题 |
| --- | --- |
| 字符身份 | 数字 / 字母是否镜像、变形、改顺序或增加字符？ |
| 板体结构 | KT 板厚度、边缘、接缝、内孔、背板是否符合素材？ |
| 灯点与电源 | 数量、安装位置及连接是否合理，有无虚增控制功能？ |
| 支撑与接触 | 底座和地面阴影是否一致，有无漂浮或不可能站立？ |
| 光影与材质 | 发光与环境受光相容，板体是否被改成另一种材质？ |
| 人物交互 | 手指、接触、持握和站位是否自然，是否遮住字符？ |
| 尺度与组合 | 高度与参照物一致，单件 / 组合和装饰是否误导数量？ |
| 使用条件 | 画面是否暗示未经支持的雨雪、户外、承重或儿童操作？ |

## 缺陷处理与验收

- 已确认产品身份错误优先纠正；未知结构先补素材，不自动补造。
- 分清后期可修、需要局部蒙版和必须重拍的内容，说明实际模型能力限制。
- 修改后逐项对照原图，不能用“自然”“高级”代替具体检查。
- 单张图无法检查背面或供电时标记无法判断；物理安全与合规必须另有真实证据。

## 待补证据

多视角实拍、装配说明、失败生成样本与纠正案例；视觉一致性、性能验证和业务效果分别记录。
