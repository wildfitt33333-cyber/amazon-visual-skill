# KT 板灯牌：灯光与光晕

## 必需事实

确认灯点布局、实际灯色、控制功能、亮灯 / 未亮灯原图及拍摄条件。无色温或亮度资料时不填数值；照片白平衡不等于产品真实色温。

## 判断流程

1. 检查灯点是否符合结构，有无 AI 新增、缺失或错误位置。
2. 查看高亮区域是否吞没字形、板体边缘和相邻灯点。
3. 检查板面、地面和人物受光是否与灯点位置和环境主光相容。
4. 对比图先核对机位、环境光、曝光与白平衡，不用不一致条件断言亮度优劣。
5. 区分装饰氛围展示与照明能力，避免虚构整场照明效果。

## 典型缺陷与修改

- 光晕连成一片 → 收敛后期光晕，保留真实灯点和字符边缘。
- 板体漂白或塑料化 → 恢复真实 KT 板纹理和环境明暗，不改变产品材质。
- 节日主题改成未确认彩灯 → 恢复实际灯色，让布景承担配色。

## Prompt 与验收

锁定灯点、灯色和材质，说明环境光、适度光晕和接触阴影。实际亮度及发光均匀性需要实拍 / 测量证据；生成图只能验收视觉一致性，不能认证性能。

## 待补证据

固定条件拍摄、参数来源、低光阅读反馈；不把更亮作为所有活动的默认优化方向。
