# KT 板灯牌：构图与阅读层级

## 适用条件

先确认主图、辅图或活动场景图，再确定数字 / 字母、单件 / 组合和主要购买问题。主图要求以当前官方美国站适用品类规则为准，活动布景不自动适用于主图。

## 判断流程

1. 单件先读出字符；组合先读出数字 / 词组，再理解灯点和结构。
2. 检查字间距、内孔、机位与遮挡，不能为对称改字形或增加字符。
3. 地面承载灯牌与接触阴影；前景不挡关键笔画，背景提供活动语境而非争夺注意力。
4. 在实际缩略图条件下检查字符辨识，记录尺寸和裁切，不凭大图断言移动端通过。
5. 辅图文字围绕尺寸、组合、装配或活动用途中的一个主要问题，不挤满小字。

## 典型缺陷与修改

- 气球占满画面，数字变成配角 → 降低装饰竞争，保留完整字形。
- 词组两端被裁切 → 调整机位和留白，不缩窄字符补救。
- 人物与灯牌同层重叠 → 移动人物或改变站位，保持尺度和自然动作。

## Prompt 与验收

明确产品、人物、布景的层次与文字安全区，锁定字符及真实比例。验收缩略图阅读、无关键遮挡、画面与包装数量一致。

## 待补证据

同 SKU 构图对照、实际缩略图预览和阅读反馈；没有固定通用留白或主体百分比。
