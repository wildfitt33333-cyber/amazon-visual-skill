# KT 板灯牌：产品尺度

## 必需事实

记录逐字符高度、宽度、板厚、支撑及组合间距；注明单位与资料来源。`1 inch = 2.54 cm`，换算与标注精度不得制造不存在的尺寸精度。

## 判断流程

1. 核对画面 SKU、字符和件数；区分主图主体占比与产品实际高度。
2. 查尺寸箭头与对应边缘是否正确，主体、支撑和包装尺寸不能混用。
3. 场景参照物与灯牌须处于合理透视和空间关系；人物身高未知时不能据此推算精确尺寸。
4. 同一组合保持各字符真实宽高，不强制等宽；地面和机位统一。
5. 标记缺少实测或无法从图片确认的比例，不给伪精确占比。

## 典型缺陷与修改

- 产品高度通过缩小人物夸大 → 依据尺寸重建合成，必要时补实拍。
- 单数字和组合使用同一尺寸标签 → 分开单件与组合测量范围。
- 低角度造成巨大感 → 用辅助规格图说明真实尺度，不将夸张透视作为卖点。

## Prompt 与验收

锁定真实尺寸、字符宽高、参照物与地面；验收尺寸标注、换算和透视一致。缺测量资料时规格图为草案，不声称已验证比例。

## 待补证据

实测图、同机位尺寸参照、尺寸预期与退货反馈；此规则不规定统一灯牌高度或主图占比。
