# Amazon US KT 板发光灯牌知识库

范围：Amazon 美国站 KT 板数字、字母发光灯牌，包括经产品事实确认的开放框架结构。活动是同一灯牌的使用场景，不引入其他商品类别。

状态：基础判断框架，尚无实测市场样本或实验结果。以下建议不是已验证的美国消费者偏好，也不代替 Amazon 官方规则、产品说明和实际照片。

## 使用方法

1. 先确认产品材质、字符、尺寸、灯点、供电和包装数量。
2. 按产品类型、活动和用户提供的受众需求选读；不要强行应用全部场景。
3. 使用视觉规则检查当前图，结合实际竞品验证购买信号和差异化机会。
4. 报告记录引用文件路径、章节、适用条件及图片证据；知识库不能代替图片证据。
5. 未来案例追加来源、日期、站点、SKU / 样本范围、证据等级和局限；失败与无结论结果同样保留。
