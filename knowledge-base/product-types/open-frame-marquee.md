# 开放框架 KT 板 Marquee 灯牌

## 结构边界与确认门槛

本条目只适用于产品资料及实拍证实的 **KT 板开放框架数字 / 字母灯牌**。`open-frame` 是结构标签，不自动等同于具体背板、灯座或装饰能力。

先取得正面、侧面、背面或装配照片，确认框架、背板是否存在、灯点安装位置、底部支撑和随附件。无法确认时标记“结构待确认”，不把普通灯牌改造成开放框架款。

## 专项视觉判断

- 检查内外轮廓、侧壁深度、空腔和背板关系，不能生成不存在的封板或透明板。
- 透视必须支持真实结构，开放处的背景透出与遮挡一致。
- 若仅轮廓承担识别，减少穿透背景的视觉干扰；仍保留空腔特征，不用假实心面补救。
- 灯点、支撑、接缝与装配路径与原图一致，不为干净画面抹掉结构证据。
- 框架内加装饰须有说明支持，不能暗示承重、固定或热安全性能；未随附物品不得计入包装。

## 常见问题 → 修改方向

- 背景穿透让字形混乱 → 调整背景对比和机位，不改变结构。
- 合成阴影看似实心板 → 根据真实空腔重建遮挡和接触关系。
- 没有结构素材却要求侧面生成 → 先补素材，侧面 Prompt 标记受阻。

## Prompt 保留项与验收

锁定已确认框架、内孔、侧壁、灯座和底座；对照多视角素材检查，无法观察的部位不能声称已验证。

## 后续证据沉淀

待补：实际结构定义、装配资料、同结构参考和用户理解反馈。不得编造行业统一结构标准。
