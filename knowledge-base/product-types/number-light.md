# KT 板数字发光灯牌

## 适用范围与待确认事实

Amazon US KT 板数字灯牌，用于生日数字、纪念数字或已确认的毕业 / 节日年份。确认具体 SKU、数字、单件 / 组合、板体尺寸、灯点、灯色、支撑、装配与包装清单。

## 专项视觉判断

- 检查 `0` 的内部空白、`1` 的轮廓、`6 / 9` 的方向和 `8` 的开口是否保留真实字形，不套用统一字体重画。
- 双位数字保持正确顺序；字符间距不能导致拆读或挤压，不机械拉伸成相同宽度。
- 组图展示 `18` 等组合时，明确本 SKU 是否包含两个数字，不暗示购买单件即可获得整套。
- 亮灯不能冲掉轮廓和灯点；KT 板边缘、实际厚度与底部接触应可辨。
- 同画面人物与灯牌尺寸一致，不能为了“大型派对感”扩大产品。

## 常见问题 → 修改方向

- 数字被气球遮挡 → 调整环境元素和视角，保留完整识别。
- 发光过曝导致数字糊成光块 → 降低不真实光晕，保留字符边缘；亮度表现以实拍核实。
- 组合数和包装数混淆 → 调整主图售卖展示，辅图独立说明组合用途与随附内容。

## Prompt 保留项与验收

锁定数字、方向、顺序、真实比例、灯点和支撑；验收逐项对照源图及 SKU，不允许生成器更换生日数字或新增灯泡。
