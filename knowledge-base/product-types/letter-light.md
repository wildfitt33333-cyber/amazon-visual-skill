# KT 板字母发光灯牌

## 适用范围与待确认事实

Amazon US KT 板单字母及已确认的字母组合。记录字母、大小写、字体原貌、每件宽高、组合顺序、SKU 数量、灯点、装配与支撑。

## 专项视觉判断

- 保留真实字形与内孔，检查 `O / Q`、`I / L` 等具体产品字符是否因角度或遮挡难以区分。
- 单字母先保证字符识别；词组兼顾单字结构与整组阅读，不能镜像或省略字符。
- 字距按真实尺寸与现场摆放调整，不拉伸不同字母制造机械等宽。
- 装饰不穿过关键笔画；人物不能挡住词组中心，低光环境也须能读出字符。
- 姓名、缩写、婚礼或求婚词组必须来自用户输入且 SKU 可实现，组合示意不等于整套售卖。

## 常见问题 → 修改方向

- 斜侧视角导致字母重叠 → 减少遮挡或改变拍摄位置，保留实际结构。
- AI 自动补字或改拼写 → 锁定逐字顺序，优先真实素材合成并人工校对。
- 完整词组掩盖单件 SKU → 明确产品展示边界与配件说明。

## Prompt 保留项与验收

逐字锁定字符、大小写、顺序、灯点与板体。验收正向阅读、无镜像、无多余字母、包装数量一致，文字图层与产品实体字符分别检查。

## 后续证据沉淀

待补：单字母 / 词组分层参考、缩略图识别、组合购买问题和活动场景表现。不能将一种词组的结果推广到所有字母。
