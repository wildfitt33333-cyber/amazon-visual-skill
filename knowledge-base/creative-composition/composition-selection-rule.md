# 创意构图选择规则

规则 ID：`CCL-SELECTION`。这是 Agent 可执行的文档决策流程，不是已实现的自动检索程序。仅服务 Amazon US KT 板数字 / 字母灯牌；不新增 Benchmark。

## 1. 输入

- 产品：数字 / 字母、实际字符组合、材质、结构、售卖内容、宽高厚、灯色及使用条件。
- 年龄 / 角色：儿童、Teen、成人、老人 / 长者；庆祝对象与购买者分别记录，未知不猜。
- 用途：生日、婚礼、求婚、毕业，以及家庭 / 室内 / 户外实际环境。
- 图片角色：搜索 / Listing 首图、场景副图、A+、品牌 / 广告图。
- 视觉目标：产品识别、尺寸理解、家庭感、社交、仪式或情绪叙事；注明用户提供还是策划假设。

数字与年龄冲突、产品无法表达所需词组或使用条件不足时先记录冲突，不偷偷改 SKU、年龄或产品能力。

## 2. 选择顺序

1. **图片角色优先**：搜索首图优先 CC-A 产品英雄构图，按实际官方条件决定背景与内容；不得因年龄或用途自动加人物和生活布景。场景用途未知时给出分支，发布状态待核实。
2. **事件优先于年龄**：求婚选择仪式动线，婚礼选择专属主题 / 新人关系，生日选择年龄数字或实际字母主题，毕业选择已确认的阶段纪念表达。
3. **产品与视觉目标适配**：完整词组需阅读空间；数字需顺序与年龄准确；多件产品都要清晰。尺寸和灯色影响机位、摆放及布光，不改变产品事实。
4. **年龄与角色调整**：使用下面的条件矩阵，用户明确主题优先，不把老年等同于行动不便，也不按性别指定装饰。
5. **按真实尺寸重算**：采用 CC-B 时核对人物、家具、地面及距离。CC-C 和 CC-D 只在不会遮挡产品时使用；CC-E 只在环境故事确有作用时使用。
6. **输出后检查**：将方案送入 Visual Quality Rules；冲突时简化为 CC-A 或重新设计，不强行保留创意。

## 3. 场景副图 / 品牌图的条件矩阵

方法定义见[构图原则](composition-principles.md)：CC-A 英雄、CC-B 人物比例、CC-C 前景遮挡、CC-D 第一视角互动、CC-E 深景深生活方式。下面均为建议组合，不是固定模板。

| 产品与用途 | 年龄 / 角色条件 | 推荐主方法 | 可选辅助与执行重点 |
| --- | --- | --- | --- |
| 数字或实际生日字母灯 / 儿童生日 | 用户明确的儿童与家庭购买者 | CC-A | CC-B 校准儿童比例；CC-E 展示家庭互动与趣味，不能遮字符或虚构年龄 |
| 数字或生日字母灯 / Teen 生日 | 明确 Teen 主题 | CC-A | CC-B 或 CC-E 表达朋友社交与派对氛围，不强制女性、坐姿或固定配色 |
| 数字或生日字母灯 / 成人生日 | 成人家庭 / 朋友庆祝 | CC-A | CC-E 展示生活方式，CC-B 解释尺度；家庭聚会与社交按实际需求选择 |
| 数字或生日字母灯 / 长者生日 | 明确纪念、陪伴或人生阶段目标 | CC-A | CC-E 展示家人关系，CC-B 按真实站姿 / 坐姿校准；不缩小人物夸大灯牌 |
| 可实现的 MARRY ME 等字母 / 求婚 | 按事件角色，年龄非主要路由 | CC-D，条件适用 | CC-A 保证词组识别；CC-E 展示仪式空间，CC-C 可形成通道入口；如手部 / 背影挡字，改用 CC-A＋CC-E |
| 已确认的首字母或婚礼字母 / 婚礼仪式、合影 | 新人与活动购买者 | CC-A | CC-B 表达人物与专属符号关系，CC-E 交代场地；新人后退而不挡产品 |
| LOVE 等字母 / 婚礼晚宴或舞池 | 新人互动与 Reception 目标 | CC-E | CC-A 保留产品视觉中心，可加 CC-B；前景共舞不得降低词组可读性 |
| 数字或字母 / 毕业 | 儿童、Teen、成人或长者的实际毕业任务 | CC-A | CC-E 展示明确的阶段庆祝，CC-B 按参与者校准；年号、学校标识和字符须有事实与授权依据 |

不是生日的数字项目不能仅凭年龄套用生日矩阵；不是求婚的字母组合不能强行组成 MARRY ME。年龄未知时按已确认事件选择方法，人物角色保留待确认。

## 4. Benchmark 与方法的关系

依照[Benchmark 匹配规则](../benchmark-rules/benchmark-selection-rule.md)选择现有参考，再抽取其构图方法；方法选择不强制依赖有案例。

- BM-001 可提供儿童生日产品 / 人物层级思路。
- BM-002 可提供 Teen 数字识别与人物空间关系思路。
- BM-003 可提供成年家庭空间与生活方式层次思路；长者需求相近时为条件参考。
- BM-004 保持一个案例组，按求婚 / 户外婚礼 / 室内晚宴子场景选择方法；不能复制字母遮挡或不同灯色。

这些不是新增案例，也不把原案例深浅景深、产品占比或A级标签直接当作方法验收通过。毕业等没有完整现有标杆时按事实独立策划并明确无主参考。

## 5. 必须输出

```text
输入与事实状态：产品 / 字符 / 尺寸 / 灯色 / 年龄角色 / 事件 / 图片位置
视觉任务与依据：用户目标 / 消费需求 / 推断与限制
主构图：方法 ID 与名称
辅助构图：方法 ID、作用；不需要时写无
为什么选择：与产品识别、受众任务、事件和图片角色的关系
如何布置：产品位置 / 人物位置 / 前中背景 / 机位 / 景深 / 光影
Benchmark 关联：案例 ID / 匹配状态 / 方法来源，或无匹配
独立重设计项：人物 / 装饰 / 字符 / 比例 / 灯光 / 文案
排除的方法：原因与冲突
验收与待补：可读性 / 产品第一视觉 / 尺度 / 接触光影 / 发布条件
```

无成图不判通过，无经营数据不宣称转化提升。执行顺序：**产品分析 → Benchmark 条件匹配 → 创意构图选择 → Visual Quality Rules 检查 → Brief / Prompt → 实际成图验收**。
