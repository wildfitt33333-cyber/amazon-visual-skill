# Marquee 商业场景创意技巧

规则 ID：`CCL-TECHNIQUES`。仅用于 Amazon US KT 板灯牌；按[构图原则](composition-principles.md)独立设计，不复制 Benchmark 内容。以下为可验证的制作方法，不能替代产品事实或经营数据。

## 1. 制造真实生活感

- 先说明谁、在什么空间、庆祝什么、正在做什么，再安排产品；生日、求婚、婚礼、毕业不能只靠换背景混用。
- 选择尺度可信的客厅、活动场地与家具，产品有真实落地、支撑和供电逻辑。实际素材中的必要结构不得为了整洁删除。
- 布置少量与事件有关的物件及自然使用痕迹，如有人使用的座位、小份花艺、庆祝桌面；不堆砌杂物或非售卖配件。
- 保留自然皮肤、放松姿态与视线交流，检查手指、衣物接触和透视，不用磨皮隐藏问题。
- 用环境光方向、接触阴影和合理灯光反馈统一产品与场景；白色 KT 板不能变成金属或透明亚克力。

验收：空间、人物与产品能够解释同一事件；缩小后产品仍先被识别，放大后接触和结构可信。真实观感不证明实拍来源。

## 2. 增加仪式感

- 生日突出准确年龄数字及家人共同庆祝；求婚突出完整 MARRY ME 表达、到达仪式中心的动线与情绪入口。
- 婚礼可突出真实售卖的首字母 / LOVE 与新人关系；毕业以用户确认的毕业主题和字符表达阶段纪念，不添加未知定制能力。
- 花艺、灯串、通道和少量装饰围绕产品组织，不以装饰规模代替仪式叙事。
- 日落、室内晚宴或柔和窗光按实际任务选择；保留本品暖黄 / 白灯颜色，不为了浪漫自动改灯色。
- 蜡烛氛围不意味着可将可燃物、热源靠近 KT 板；实际布置须符合产品使用说明，不能示范未知安全使用条件。

验收：无需额外标题也能理解事件；产品是事件的关键符号，装饰不抢主体。户外构图先核实场地与本品使用能力。

## 3. 避免普通摆拍

- 将“站在产品旁看镜头”替换为有理由的轻动作，如自然交流、回望或迎接家人；不是禁止正常合影。
- 人物身体与视线可形成指向产品的线索，避免每个人同时僵硬正面站立。
- 安排适度前后距离，保留真实透视；不要为制造景深把产品虚化或改变物理尺寸。
- 姿态设计必须符合空间、支撑和产品承重事实，不安排坐在灯牌、攀爬灯牌或遮字符的动作。

验收：动作与庆祝任务相关、肢体自然、产品可读；不把所有棚拍方法判为低质，纯产品首图仍可采用专业棚拍。

## 4. 让产品成为故事中心

- 明确一张图的单一任务：数字表达生日阶段、词组表达求婚意图、首字母表达已确认的婚礼主题。
- 人物动作、视线、空间动线服务这个表达；高亮背景牌、密集装饰或大面积人脸不得压过灯牌。
- 完整保留字符轮廓和阅读顺序，产品表面、厚度与灯泡是可信证据，不被光晕吞没。
- 用减少竞争元素、移动机位或调整前后位置恢复产品权重，不增加不存在的尺寸、亮度或套装内容。

验收：用户先识别所售灯牌，再理解事件；不能出现“只看懂派对，看不懂商品”的情况。

## 5. 利用人物支持购买理解与情绪代入

- 人物提供使用情境、经校准的尺度参照和情绪连接，帮助消费者想象自身庆祝活动。
- 区分购买者与庆祝对象；根据用户给出的角色安排人物，不凭年龄强制性别、饮酒或固定配色。
- 儿童可强调亲子交流，Teen 可强调朋友互动，成人可强调家庭 / 社交，长者可强调纪念与陪伴；均为条件方向，不是普遍偏好。
- 保持人物次于产品，人物参照不能取代尺寸资料。生活场景一般用于副图 / 品牌任务，不绕过首图规则。

验收：人物增加理解且不遮挡产品，不误导所售内容。转化收益属于待验证假设；需要实际 CVR / 实验口径与混杂因素分析，不能仅凭画面承诺提升。

## 6. Brief 与 Prompt 的落地字段

每次记录：图片角色、事件任务、主 / 辅构图方法、产品事实、人物作用、空间距离、机位、景深、光源、允许调整项、禁止改动项及验收方式。Prompt 保留本品结构、真实比例和灯色，人物、装饰及场地独立设计；只有必要且可访问的素材才能列为参考输入。

成图后分别记录通过 / 未通过 / 待执行 / 无法判断 / 不适用，发现遮挡、比例或光影问题先修复，再讨论创意增量。发布要求按[美国站主图规则](../visual-quality-rules/amazon-main-image-rule.md)检查。
