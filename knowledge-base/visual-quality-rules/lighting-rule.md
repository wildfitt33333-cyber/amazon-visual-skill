# 发光灯牌灯光判断规则

规则 ID：`VQR-LIGHTING`。范围：Amazon US KT 板数字 / 字母灯牌。判断灯点与环境的可信关系，不以生成效果证明性能。

## 必须保证

- **产品与环境受光一致**：方向、阴影、反射和色彩作用相容，不要求所有光源色温相同。
- 暖黄灯保留已确认的暖黄色发光观感，不变成未经支持的彩灯或超亮照明。
- 冷白 / 中性白灯保留对应产品真实灯色，不为了浪漫氛围统一改成暖黄；色温未知不编造数值。
- 地面具有合理接触阴影和必要照明反馈；反馈程度按光线、距离与材质判断，不强行添加强亮斑或镜面倒影。
- 灯点位置、数量、灯座与产品结构一致，高光不吞没字符边缘、内孔和 KT 板细节。

## 避免

- 灯光漂浮：光晕与灯点错位、产品无地面接触、环境没有合理对应关系。
- 产品背后错误光影：背部亮区、阴影方向或穿透不符合已知光源与结构。
- 人物受光不一致：皮肤、服装、持物的明暗与光源位置冲突。
- 过度黄染、塑料板体、全场被灯牌照亮，或反射亮度超过合理来源。

冷白灯与暖色串灯可以共同存在；夜间场景不要求肤色完全相同，需分析混合光源是否合理。

## 判断与修复

1. 读取灯色、亮灯 / 未亮灯素材、拍摄条件与说明；缺失标记未知。
2. 列出窗光、环境灯、灯牌及烛光状道具等可见来源，检查方向、遮挡和接触。
3. 用范围受限的曝光、光晕和合成调整修复观感，不改变产品灯点和真实颜色。
4. 对比需同条件；亮度、照度、色温与均匀性性能通过实拍 / 测量核实。

## 验收

逐项记录灯点 / 字形保留、板体细节、地面与人物反馈、阴影 / 反射相容、过曝和光晕问题。无地面或人物时对应项不适用，未检查项不得通过。

输出规则 ID、光源与区域证据、状态、原因、修复和验收方法。对应视觉量表 Q4、Q5、Q6，补充依据见 [灯光与光晕](../visual-rules/lighting-and-glow.md)。
