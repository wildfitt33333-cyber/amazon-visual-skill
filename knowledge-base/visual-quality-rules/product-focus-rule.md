# 产品视觉中心判断规则

规则 ID：`VQR-FOCUS`。范围：Amazon US KT 板发光数字灯 / 字母灯。用于分析、优化及成图验收，不作为已验证的点击率模型。

## 视觉优先级

1. **第一视觉：产品**。灯牌是核心，字符、方向、顺序与售卖数量正确；尺寸比例真实，结构完整；可见边缘、板厚、灯泡细节清楚，不为美化改变字形、材质或支撑。
2. **第二视觉：人物**。解释使用场景、真实尺度和情绪价值，不抢产品主体。精确尺寸仍以产品资料为准，未知人物身高不能充当标尺。
3. **第三视觉：装饰与环境**。气球、花艺、背景服务生日 / 求婚 / 婚礼叙事，不遮挡关键结构或暗示随附物品。

## 判断标准

| 优秀表现 | 不优秀表现 |
| --- | --- |
| 第一眼能读出产品与字符 | 人物面部、礼服或动作压过灯牌 |
| 产品占主要视觉区域，轮廓和灯点清楚 | 气球抢视觉、产品缩成背景装饰 |
| 真实尺度、完整结构与包装边界一致 | 拉伸灯牌、缩小人物、隐藏真实支撑 |
| 背景帮助想象用途，吸引力有具体机制 | 背景复杂，用户难以判断售卖主体 |

“主要视觉面积”是布局目标，不是固定百分比。结合对比、清晰度、位置与遮挡判断，不能只靠面积判第一视觉；情绪品牌图可保留较大人物，但必须明确灯牌身份，不自动按产品主图判优秀。

## 检查 → 优化 → 验收

- 先看正常显示与实际缩略图，记录尺寸、裁切、第一注意对象和字符辨识；未检查就标记待执行。
- 问题定位到图片区域：主体偏小、人物过亮、装饰遮字或背景竞争。
- 优先调整机位、留白、人物位置、布景密度和对比，不改实际产品高度或灯泡布局。
- 成图核对字符、数量、尺度、边缘、内孔及结构，确认人物 / 装饰不遮关键阅读区域。
- 没有原产品多视角时隐藏部位标记无法判断，不声称结构完整性已全部验证。

输出：规则 ID、观察 / 证据、通过 / 未通过 / 待执行 / 无法判断 / 不适用、原因、修改动作、验收条件。对应 [视觉评分](../../case-library/evaluation/visual-quality-score.md) Q1、Q2、Q3、Q5、Q7，不另造收益分数。
