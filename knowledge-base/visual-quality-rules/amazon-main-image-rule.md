# Amazon US Marquee 主图判断规则

规则 ID：`VQR-MAIN-IMAGE`。只服务 KT 板灯牌。以下优先级为内部设计判断，不代替当前 Amazon 美国站品类官方规定，也不认证点击提升。

## 先确定图片位置与适用要求

- 区分 Amazon 搜索 / Listing 首图、生活场景副图、A+ 和品牌 / 广告图，不能把“场景主视觉”自动当可发布首图。
- 核实对应美国站品类的背景、文字、道具、产品占比及售卖内容要求，记录官方来源、检查日期和适用范围。
- 常见首图要求为纯白产品展示，但具体规则与例外需核实；未知时标记待核实，不直接认定合规或违规。
- 人物、蛋糕、气球、花艺和生活背景即使漂亮，也不能绕过首图条件。明确为受限首图时准备产品展示方向，场景另作副图建议，不悄悄替用户改变用途。

## 主图优化优先级

| 顺序 | 目标 | 灯牌执行方式 |
| --- | --- | --- |
| 1 | 产品识别 | 看清数字 / 字母、顺序、真实售卖主体和发光属性 |
| 2 | 产品尺寸展示 | 真实比例、完整结构和清楚角度；不夸大高度，尺寸标签按位置规则判断 |
| 3 | 使用场景 | 首图在允许范围内暗示用途；完整家庭 / 仪式叙事可通过场景副图解释 |
| 4 | 情绪价值 | 以可信产品和相关用途建立吸引力，不能牺牲识别或合规 |

尺寸不等于越大越好；主图可展示真实比例，但精确高度通常仍需有依据的规格说明。人物参照、生活背景和文字不是为了满足本表就必须加进首图。

## 优秀与不优秀的判断

优秀主图目标：

- 产品在约三秒的设计检查中易被识别，灯牌与字符清楚。
- 用户理解所售商品及基本用途，包装数量不误导。
- 有真实产品特点和清晰视觉吸引力，轮廓、板体与灯点可信。

避免：只追求漂亮而看不懂产品；装饰超过主体；场景过于复杂；通过夸大亮度、改材质、虚增组合制造点击。

“三秒”是设计启发式，不是已经验证的用户实验。若实际进行限时检查，记录对象、显示尺寸、步骤与结果；未执行不称已通过。只看图片不能证明购买欲或 CTR 提升。

## 优化与验收

1. 范围与官方要求先检查；已证实事实错误或规则冲突先纠正。
2. 在实际搜索缩略图条件下检查产品与字符识别、裁切、轮廓和必要结构。
3. 再调整主体布局、留白、视角和可信亮灯表现；不强行添加背景或情绪人物。
4. 核对实际 SKU 件数、3FT / 4FT 等标称规格依据与素材，未确认不能写成认证信息。
5. 分别记录设计可读性与发布规则状态，任何未核实发布前提不得判为“可直接发布”。

输出规则 ID、图片角色、官方依据与状态、实际视觉观察、优先级、修改项、待补信息及验收条件。CTR 实测另按 [点击因素](../../case-library/evaluation/amazon-ctr-factor.md)判断。
