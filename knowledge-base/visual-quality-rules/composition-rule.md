# KT 板灯牌构图判断规则

规则 ID：`VQR-COMPOSITION`。在确定图片角色、实际 SKU 与活动后使用。主图不因本规则添加生活场景；参考图的构图也须经本规则复核。

## 优秀构图原则

- 产品位于视觉中心或适合的黄金区域，灯牌先被识别；黄金分割是可用方法，不是强制坐标。
- 人物通过视线、位置或自然动作与产品建立关系，不需要强行触摸，也不遮住关键笔画。
- 前景引导视线，中景承载灯牌及相关行为，背景交代家庭 / 仪式空间。
- 使用符合镜头与空间关系的自然景深，主体细节清楚；不得靠过度虚化隐藏安装错误。
- 数字组合和词组有真实字距与共同透视，保留内孔、边缘、地面接触和阅读顺序。

## 避免的问题

- 产品贴边或裁断关键结构；预留符合实际显示与裁切条件的安全边距。
- 人物、手部、礼服或装饰遮挡字符，使词组无法完整辨识。
- 花艺、气球、背景文字或亮点竞争主体。
- 所有元素挤在同一平面、缺少遮挡逻辑和空间关系。

白底产品图可以简洁单层，不强行增加前中背景；场景图也不要求每次放置前景道具。规则判断依据是沟通任务与空间可信度。

## 优化与验收顺序

1. 先确认主要图片任务与视线入口，再检查产品与人物层级。
2. 修复关键遮挡和裁切，调整机位 / 站位 / 物品位置，不重画字形或拉伸产品。
3. 简化竞争元素，再安排空间深度和文字安全区。
4. 在同样显示尺寸下复核字形、顺序、留白、层次与焦点，记录实际条件。

对浪漫 Benchmark 可借鉴人物入口与动线，但不能复制词组遮挡；保留组内差异，不因参考等级跳过检查。
