# Benchmark 案例匹配规则

规则 ID：`BMR-SELECTION`。适用范围：Amazon 美国站 KT 板数字 / 字母发光灯牌。

Benchmark 是视觉方法参考，不是可直接复制的设计稿。依据当前产品、活动、图片用途、受众需求及消费者心理匹配；案例等级不替代事实核验、视觉验收或经营效果证据。只调用[现有案例索引](../../case-library/benchmark-cases/index.md)，不新增案例。

## 1. 输入与匹配顺序

先记录产品资料、图片角色、庆祝对象与购买者、实际主题、视觉目标和资料来源。消费者心理从用户反馈、购买任务或研究资料提取；无证据时仅标记为假设，不从年龄、性别或照片外观推断偏好。

按以下顺序决策：

1. **事实与用途约束**：确认 KT 板产品、实际 SKU、字符组合、售卖件数、图片位置及允许的使用条件。搜索首图与场景副图不能混用；官方要求未知时标记待核实。
2. **活动与主题**：先区分生日、求婚、婚礼等事件，再检查数字 / 字母含义。不能仅因尺寸相同选错活动，也不能把求婚布景套成生日派对。
3. **产品匹配**：比较产品类型、尺寸、灯色及结构，列出相同项、差异项与未知项。
4. **受众与心理需求**：判断庆祝对象、购买者、家庭 / 社交关系以及纪念、互动、仪式等目标；年龄作为条件，不覆盖用户明确需求。
5. **迁移判断**：读取候选案例全文及可访问图片，输出匹配状态、参考元素、重设计项与验收条件。只有文本记录时说明图片观察限制。

没有完整匹配可以选择有限方法借鉴，也可以不调用案例；不得为了输出案例强行匹配或编造分数。

## 2. 产品匹配维度

| 维度 | 必须比较 | 匹配与迁移规则 |
| --- | --- | --- |
| 产品类型 | 数字灯 / 字母灯；实际围边、开放结构和支撑 | 同类型优先；跨类型只借鉴构图等方法，不替换本品结构 |
| 数字 / 字母主题 | 实际年龄数字、姓名首字母、MARRY ME、LOVE 等 | 字符以当前 SKU 和任务为准；年龄与数字冲突先记录，不擅自改其中一项 |
| 产品尺寸 | 2FT / 3FT / 4FT 及实际高度、宽度、厚度 | 相同尺寸可减少迁移工作，但仍须实测依据；不同尺寸重新校准空间、机位和人物关系 |
| 灯光颜色 | 暖黄灯 / 白灯，白灯的实际冷暖类别 | 保留当前产品灯色；异灯色案例只能条件借鉴环境与布光方式，不能把暖黄改白或把白灯自动暖化 |
| 使用场景 | 家庭生日、Teen 派对、海边求婚、草坪婚礼、室内晚宴等 | 事件、空间、使用能力与图片角色共同匹配；场景参考不证明本品防水、户外或定制能力 |

尺寸换算：2FT 约 61cm、3FT 约 91cm、4FT 约 122cm。**2FT 不等于已有尺寸规则中的 2.3FT（约 70cm）**，不得归并。非整档尺寸按实际 SKU 记录，不修改[尺寸与比例规则](../product-rules/size-scale-rule.md)来迁就案例。

人物与产品比例由本品尺寸、人物身高 / 姿态、家具、共同地面和透视决定；不得沿用参考图像素比例，也不得通过缩小人物夸大产品。

## 3. 用户年龄与消费者心理匹配

下列重点为候选策划方向，不是已验证的年龄群体偏好。购买者与庆祝对象分开记录，实际主题和用户反馈优先。

| 年龄 / 活动阶段 | 参考重点 | 可考虑的心理需求（待证据支持） | 现有案例路由与限制 |
| --- | --- | --- | --- |
| 儿童生日 | 互动性、趣味、家庭感 | 参与感、亲子陪伴、生日记忆 | 字母场景优先 BM-001；儿童数字没有完整主匹配，可有限借鉴 BM-001 层级与 BM-002 数字识别，不能套用 Teen 人物与主题 |
| Teen 生日 | 年轻感、社交、派对氛围 | 与朋友庆祝、个人表达、分享纪念 | 数字 Teen 场景优先 BM-002；实际年龄数字重新核对，不默认女性或黑白金配色 |
| 30–50 岁生日 | 高级生活方式、家庭聚会、社交庆祝 | 家庭 / 朋友共同庆祝、有品质的使用体验 | 家庭数字生日条件参考 BM-003；不强制女性人物、饮酒或中性色，也不把 50 改为输入未提供的年龄 |
| 60 岁及以上生日 | 家庭纪念、温暖陪伴、人生阶段庆祝 | 重要生日纪念、家人陪伴、共同回忆 | 当前无专属长者标杆；需求相似时条件借鉴 BM-003，不称完全匹配，不自动采用衰老或行动不便形象 |

年龄边界不作机械路由：51–59 岁根据实际成年生日需求判断；18 岁依具体活动与用户角色判断 Teen / Adult 方向。年龄未知不猜测，60 岁以上不能将 BM-003 的原始参考范围擅自扩展成已验证适用范围。

求婚与婚礼优先按事件、人物角色和情绪任务调用 BM-004，而非仅凭年龄调用成年生日案例。保留 BM-004 为一个参考组，并记录所选子图。

## 4. Benchmark 使用边界

### 允许参考

- **构图逻辑**：视觉入口、产品位置、前中背景层次与留白；按当前画幅及产品重新布局。
- **产品与人物关系**：人物如何提供情绪、互动和尺度语境；依据本次角色、实测尺寸重新安排姿态与距离。
- **色彩方向**：环境配色和主体分离方式；不能改变真实板材颜色、灯色或把单例当全市场审美。
- **光影方式**：主光方向、软硬关系、环境与产品发光的协调；按当前场地和材质重新计算阴影、反射及光照反馈。

### 禁止复制

- **人物**：不复制原人物面貌、身份或具体姿势；为本任务独立设计人物角色与自然动作。
- **装饰**：不照搬具体花艺、气球、家具和布景组合；同类元素仅在本任务需要时重新选择、布置，且不误导售卖内容。
- **文案**：不复制参考中的标语、姓名、日期、年龄或品牌文字；按事实与图片位置决定是否独立编写。
- **产品比例**：不套用参考的占画面比例、人物高度关系、字符宽高或产品间距；保留本品内部比例并重算场景尺度。

不得复制参考图片本身、专有标识或未知授权素材；借鉴方法不等于取得素材使用权。不得用 Benchmark 替代本品照片或产品规格。

## 5. 匹配状态与输出规范

沿用案例索引的状态，不另建评分体系：

- **主参考（primary）**：关键主题、产品与图片任务相符，实际资料支持迁移；仍需视觉规则检查。
- **条件参考（conditional）**：方向接近，但存在尺寸、灯色、人群、场地或图片角色差异；明确限制与重设计工作。
- **方法借鉴（technique_only）**：仅借鉴某一视觉方法，不称整体适配。
- **不适用（excluded）**：事件、用途或事实约束不相容，记录原因。
- **无匹配（no_match）**：现有库缺少适合主参考；继续独立策划，不新增或虚构案例。

每次输出必须包含：

```text
输入需求：产品类型 / 字符主题 / 实际尺寸 / 灯色 / 活动 / 图片角色
受众与心理需求：庆祝对象 / 购买者 / 用户明确目标 / 假设与来源
调用结果：案例 ID / BM-004 子图 ID（如适用）/ 匹配状态
为什么选择：相同项 / 差异项 / 未知项 / 与视觉目标的关系
借鉴哪些视觉元素：构图 / 产品人物关系 / 色彩 / 光影，关联案例章节或图号
哪些元素重新设计：字符 / 尺度 / 人物 / 装饰 / 文案 / 布光及图片角色
不适用部分：不能迁移的元素、能力或发布条件
验收条件：产品保真 / 字符可读 / 真实尺度 / 层级 / 光影 / 图片用途
待核实项：缺少的素材、尺寸、SKU 或官方要求
```

## 6. 接入视觉设计流程

执行：**产品分析 → 本规则筛选 → 案例全文与图片核查 → Visual Quality Rules 检查 → 独立设计方案 → Prompt → 实际成图验收**。

将匹配理由与重设计项同步写入 Brief、Prompt 和验收清单。参考元素不满足[视觉质量规则](../README.md)时应修正或舍弃，不因为 A 级标签保留缺陷。案例调用不证明 TOP 趋势、CTR / CVR 提升或发布合规；这些另需市场、实验和官方规则证据。
