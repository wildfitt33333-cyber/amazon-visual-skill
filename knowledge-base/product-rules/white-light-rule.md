# 白灯产品规则

规则 ID：`PR-WHITE-LIGHT`。适用于已确认的白光 KT 板数字 / 字母灯牌。先区分实际冷白、中性白或其他已明确白光规格，不把所有白灯强制变蓝。

## 必须

- 保持产品真实白色灯光；冷白产品保留冷白观感，中性白保留中性白，不能自动暖化为黄色灯泡。
- 周围板面、地面和人物的光照反馈与实际灯色、距离和材质相容。冷白产品应有合理冷白光作用，但不强行将整个场景染蓝。
- 白色板材保持真实本色，不把灯泡或板体全局改黄；混合暖光造成的局部受光需合理可解释。
- 暖色串灯、烛光和白色灯牌可以共存，分别保持来源，不为统一氛围改变产品灯色。
- 保留灯点布局、字符轮廓、板体结构与实际亮灯素材关系。

## 避免

- AI 自动暖化，尤其将婚礼白灯变成 Benchmark 中其他产品的暖黄灯。
- 灯光颜色错误、过强蓝染、过曝吞字、无来源的反射和亮区。
- 用照片白平衡反推精确色温，或暗示本品可以任意调色。

## 判断与验收

核实 SKU 与灯色素材 → 分离环境光源 → 锁定白光 → 检查局部反馈 → 成图对照灯色与白板，记录检查条件。

白光类别未知时只写“白光待规格确认”，不编造冷白色温。无人物 / 地面则对应反馈项不适用；性能与真实色温需资料或测量，不由生成图认证。
