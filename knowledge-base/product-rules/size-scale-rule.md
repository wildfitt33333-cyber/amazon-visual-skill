# KT 板灯牌尺寸与人物比例规则

规则 ID：`PR-SIZE-SCALE`。仅服务 Amazon US KT 板数字 / 字母灯牌。尺寸依据实际 SKU，不用 Benchmark 或人物外观反推规格。

## 尺寸档位与场景参考

| 标称高度 | 换算 | 使用方向 | 人物关系与判断限制 |
| --- | --- | --- | --- |
| 4FT | 48 in = 121.92 cm，约 122 cm | 大型生日、求婚、婚礼 | 站姿需按成人实际身高和人体比例计算；坐姿需核对坐面与头顶高度，可能与坐姿人物高度接近 |
| 3FT | 36 in = 91.44 cm，约 91 cm | 儿童互动、生日、求婚、婚礼 | 成人站姿可接近臀部区域，具体位置由身高和姿态决定；儿童不得按统一高度处理 |
| 2.3FT | 27.6 in = 70.104 cm，约 70 cm | 卧室、小空间的条件场景 | 先核对摆放位置、家具与供电条件，不把小空间用途解释为额外功能 |

场景为策划方向，不认证每个 SKU 都适用于户外、卧室照明或儿童操作，也不规定所有字符宽度一致。

## 关于人物高度的必要校准

- “4FT 成人站立接近胸口 / 肩部”只能作为待核对的构图描述，**不能作为默认物理比例**。122 cm 对许多成年人并不到肩部，不能缩小人物或放大灯牌来实现这个位置。
- 若必须验证胸口 / 肩部参照，取得人物身高、身体位置、地面与机位依据；不成立时纠正场景关系，保留真实 4FT。
- “坐姿接近人物高度”取决于坐面高度、躯干与姿势，不等于灯牌必须与人物头顶等高。
- “3FT 约臀部高度”是粗略参照，不是年龄或性别统一标准；3FT 灯牌与儿童比例按实际人物资料判断。

## 生成与检查流程

1. 锁定字符、实际高度 / 宽度 / 厚度、支撑以及组合件数，区分产品高度和包装高度。
2. 记录人物站姿 / 坐姿、身高来源、家具尺度、共同地面和前后距离；缺资料时标记尺度未验证。
3. 同一距离与近似正面条件下，可用产品高度 / 人物高度检查大致比例；不同景深、机位或姿态不能直接比较像素高度。
4. 生成场景必须保持真实比例；主体占画面大小通过机位和裁切调整，不改产品或人物物理尺寸。
5. 对照实测与源图验收字符宽高、地面、透视、接触及尺寸标注；未知人物身高不作精确标尺。

输出档位、资料来源、人物比例约束、缺失项、状态与验收方法。精确比例缺资料时 Prompt 为条件草案，不声称已验证。
