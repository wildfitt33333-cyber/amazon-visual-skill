# KT 板灯牌材质与结构规则

规则 ID：`PR-MATERIAL`。适用于本项目白色 KT 板数字 / 字母灯牌，外观必须以实际 SKU 多视角素材为准。

## 必须保留

- 白色板材与真实表面，不因布景配色改变产品本色。
- 正面平整，保留实际切口、接缝、厚度、边缘与字符内孔；平整不等于抹掉灯点或装配结构。
- 有围边、无围边、背板与开放框架分别核实，不能仅凭名称认为结构相同。
- **无围边产品需展示其真实开放结构**，不得自动添加侧壁、封板或边框。若背板 / 空腔定义不清，先补侧面与背面素材。
- 支撑、灯座、底座和随附件按事实呈现；不得为干净画面删除必要结构。

## 避免

- 将 KT 板渲染成金属质感、镀层或不存在的镜面高光。
- 添加亚克力透明感、玻璃边缘或虚构透光结构。
- 改变厚度、字符、围边、背板、灯座、开口与装配方式。
- 以参考图结构覆盖本品结构，或以“高级感”作为升级材质的理由。

## 判断与验收

先确认材质 → 对照正面 / 侧面 / 背面 → 锁定结构 → 将不改项写入 Brief 和 Prompt → 成图检查边缘、厚度、内孔、接触与光泽。

可见部位与资料相符才能判通过，隐藏结构或缺失角度标记无法判断。开放框架知识只用于已确认结构，详见 [开放框架灯牌](../product-types/open-frame-marquee.md)。
