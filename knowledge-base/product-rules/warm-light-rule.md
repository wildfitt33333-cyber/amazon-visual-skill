# 暖黄色灯泡产品规则

规则 ID：`PR-WARM-LIGHT`。仅在 SKU 或可靠原图确认本品为暖黄灯时适用；没有色温数值不自行填 Kelvin 参数。

## 必须

- 灯泡 / 灯点呈真实暖黄发光观感，与真实位置、数量和灯座相符，不像平面贴图。
- 光线影响邻近板面及周围环境，强度与光源、距离、遮挡和环境明暗相容。
- 地面存在合理接触阴影与必要光照反馈；无可见地面时不适用，粗糙地面不强行生成镜面反射。
- 邻近人物在物理条件支持时受到暖光影响，肤色保持自然；人物很远或日光较强时，不强制全身明显泛黄。
- 保留字形、KT 板本色、边缘和厚度，不让曝光吞没轮廓。

## 避免

- 灯泡像贴图、光晕悬浮、过强光晕将相邻灯点连成光块。
- 背景色污染产品，使白板失去真实外观；合理局部暖色受光可以保留，不能把整件本色改黄。
- 用更亮效果暗示未经证实的照明性能，或把产品改成其他灯色。

## 判断与验收

核实灯色 → 分析场景主光与灯点 → 检查局部受光和地面 / 人物 → 调整曝光与光晕 → 对照源图复查。

输出灯色来源、光源关系、修改范围、状态和验收方法；生成图只验收观感保真，不认证实际亮度或灯泡性能。缺亮灯素材时保留原图灯点，不虚构效果。
