# KT 板灯牌购买转化视觉因素评价

标准版本：`marquee-conversion-v1`。适用于 Amazon US KT 板数字 / 字母灯牌详情页图片组及已确认的视觉触点。目标是评估购买信息是否清楚、预期是否真实，再验证经营结果。

## 1. 灯牌专项购买因素

| ID | 因素 | 图片要回答的问题 | 检查与事实边界 |
| --- | --- | --- | --- |
| K1 | 字符与套装匹配 | 买到哪个数字 / 字母、几件、是否含整组？ | SKU、顺序、组合与包装一致，活动示意不能混淆随附件 |
| K2 | 尺寸与空间预期 | 实际多高、多宽，是否适合布置位置？ | 有依据的尺寸与英制标注，人物尺度合理，不夸大大型感 |
| K3 | 发光效果预期 | 实际灯色与亮灯观感是什么？ | 有条件记录的实拍与可信光晕；不暗示未知亮度或变色功能 |
| K4 | KT 板结构理解 | 板体、厚度、支撑和开放结构是什么？ | 与真实素材一致，不升级材质或隐藏影响使用的结构 |
| K5 | 装配与供电理解 | 如何组装、摆放、连接，需要什么？ | 说明和配件有据；不能因画面无电线就暗示无线或电池供电 |
| K6 | 活动与用途匹配 | 是否支持我的数字、词组、年份与场景？ | 输入字符能实现，用途符合已确认环境条件，不编造适用性 |
| K7 | 可信使用条件 | 展示环境与操作是否真实可行？ | 不借户外、雨雪、儿童互动暗示未经支持的性能或认证 |
| K8 | 信息完整与顺序 | 关键顾虑是否被逐项回答？ | 图片组不只重复布景；必要文案可读且事实一致 |
| K9 | 差异化价值 | 为什么该产品适合我的任务？ | 真实特点或表达优势有证据，不复制竞品功能或夸张效果 |

人物、装饰与场景只解释灯牌用途，不引入其他售卖主体。年龄或活动标签不自动决定购买心理。

## 2. 评价方法

- 每项记录问题 / 任务 ID、图片与来源、原 / 改表现、购买顾虑、机制假设、事实核实状态、验收与数据证据。
- 因素状态：缺失或误导 / 部分解释 / 清楚解释 / 无法判断 / 不适用。已证实误导优先纠正，不用综合分抵消。
- 未提供用户反馈时，顾虑只是任务假设；不能声称全部美国买家都有同样顾虑。
- 视觉表达完整不证明 CVR 提升，成图分数另按 [视觉量表](visual-quality-score.md)评审。

## 3. CVR 口径

先选择一个来源明确且前后可比的指标，保存平台原始名称与定义：

- 订单 / 点击、订单 / 会话等不能混用；售出件数 / 会话不等同订单转化率。
- 分子是订单、买家还是件数，分母是点击、会话还是用户，均明确注明；可能存在多订单，不能默认为每个分母单位一次转化。
- 广告与自然流量分开，记录归因窗口、成熟度、重复计数与数据截止时间。

```text
选定转化指标 = 定义明确的分子计数 / 分母计数
绝对变化（百分点） = (rate_variant - rate_control) × 100
相对变化（%） = (rate_variant / rate_control - 1) × 100
```

零分母不计算，对照率为 0 不计算相对变化。汇总使用原始计数，不平均比率；非二元或非独立数据不能直接套用二项分布显著性判断。

## 4. 优化效果验证流程

1. 锁定原 / 改图片组、实际生效时间、SKU、价格与内容版本，区别计划图和真实上线图。
2. 定义主指标、护栏、实验单位、分流、时长、最小有意义变化及分析方法。
3. 记录样本、窗口、流量构成和活动季节；非随机前后观察不作确定因果归因。
4. 检查促销、库存、评价、配送、流量质量、广告策略及同步文案改动等因素。
5. 展示效果估计、不确定性和数据质量；没有充分证据时写无明确差异或无效实验，不宣布成功。
6. 结合 [CTR](amazon-ctr-factor.md)、订单 / 销售表现、取消与退货原因评估整体权衡。前后流量不同导致 CVR 变化时，不将其直接归因于图片。
7. 整组或多个模块同时改动，只能评价组合方案；单因素效果需可隔离的实验设计。

## 5. 统一结果与经验记录

- 分开记录视觉验收、CTR 结果、CVR 结果和整体经营判断；四者可以不同。
- 结果：未验证 / 改善 / 恶化 / 无明确差异 / 无效实验，注明观察或实验依据。
- 对尺寸误解、数量误解、发光预期与安装理解相关退货反馈，记录来源、范围和时间；不能单凭几条评论证明改图有效。
- 只有视觉改善而无经营证据时写“视觉改善，购买转化未验证”，不进入经营成功结论。
- 经验记录包含适用 SKU、字符组合、活动、受众需求、流量、时期、限制和复核状态；保留失败与无结论，不自动晋升长期规则。

使用 [案例模板](../templates/case-analysis-template.md)记录，不填入虚构指标或案例。
