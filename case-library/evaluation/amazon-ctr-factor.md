# Amazon US 灯牌点击率视觉因素评价

标准版本：`marquee-ctr-v1`。仅适用于 KT 板数字 / 字母灯牌在已确认曝光入口中的视觉表现。以下是待验证的影响机制，不是固定收益模型。

## 1. 明确点击发生在哪里

- 优先评价搜索结果或广告入口实际展示的主图；记录入口、位置、设备、尺寸与裁切。
- 未在点击前展示的辅图不能解释该次搜索点击提升；若广告使用辅图或创意图，应记录实际资产与位置。
- 价格、评价、排名、配送、促销和投放条件同样影响点击，不能归因于图片单一因素。

## 2. 灯牌专项视觉因素

| ID | 因素 | 检查内容 | 预期机制假设 / 边界 |
| --- | --- | --- | --- |
| C1 | 字符辨识 | 数字 / 字母方向、顺序、内孔和边缘在缩略图中可读 | 减少识别时间，不因字形错误制造吸引力 |
| C2 | 主体显著性 | 灯牌占画面比例、留白、对比、裁切 | 产品容易被注意；不是越大越好，也不是实际尺寸提升 |
| C3 | 可信亮灯表现 | 灯点、光晕、边缘、曝光与真实灯色 | 帮助理解发光属性；更亮不必然点击更高 |
| C4 | 售卖组合清晰 | 单件或组合、字符 / 数量与 SKU 一致 | 减少误点，不能虚增整套以换点击 |
| C5 | 熟悉购买信号 | 同类参考中有据的视角和产品表达 | 降低理解成本，常见模式不等于有效 |
| C6 | 合理记忆点 | 合规角度、真实特点与受控差异化 | 提供辨识差异，不改变板体、灯色或功能 |
| C7 | 入口适配 | 实际手机 / 广告展示下的轮廓、裁切和背景 | 避免全尺寸清楚但缩略图失败 |

活动布景、人物、文字是否可用于该入口先核实适用规则；不能以点击假设突破主图要求。

## 3. 因素记录方式

每项记录：原图 / 改图观察、具体图片区域、证据、变化方向、机制假设、状态和风险。

状态：阻碍 / 基本满足 / 可探索 / 无法判断 / 不适用。没有实测时只能写“视觉假设改善”，不评估预计 CTR 增幅。需要整体视觉分时引用 [视觉量表](visual-quality-score.md)，不额外生成“点击预测分”。

## 4. 实测口径与计算

```text
CTR = 同范围点击数 / 曝光数
绝对变化（百分点） = (CTR_variant - CTR_control) × 100
相对变化（%） = (CTR_variant / CTR_control - 1) × 100
```

- 曝光为 0 时 CTR 不计算；对照 CTR 为 0 时相对变化不计算。
- 原始计数、数据来源、实际图片版本、时段 / 时区、设备、流量、广告类型 / 位置、关键词与归因范围必须记录。
- 汇总使用同口径点击与曝光计数，不平均各组百分比；多次曝光 / 点击可能来自相同用户，统计方法需考虑实际分流单位。
- 先确认曝光资产真的变化及生效时间，平台延迟、缓存或重叠窗口标记限制。

## 5. 比较与判定

1. 实验前定义主指标、流量分配、时长、最小有意义变化、护栏和分析方法，不在看到结果后更改判胜规则。
2. 记录随机化或前后观察方式；不同广告位置、关键词、设备或活动时期不直接混比。
3. 同步价格、评价、促销、库存、广告出价和流量变化均记录为潜在干扰。
4. 展示样本量、效果估计与不确定性；小样本或无有效实验方法不能声称显著改善。
5. 状态区分未验证、改善、恶化、无明确差异和无效实验。CTR 方向变化与因果证据分别报告。
6. 结合 [CVR](conversion-factor.md)、订单质量和退货反馈检查是否吸引了不匹配点击；CTR 上升不能单独宣布整体差转优成功。

## 6. 统一输出

入口与图片版本 → C1–C7 观察表 → 视觉改动及机制假设 → 点击 / 曝光与 CTR → 实验可比性 → 结果、不确定性及护栏 → 可复用范围。

尚未实测写“CTR 效果未验证”。整张图同时改动多个元素时，只能评价组合策略，不能给单因素贡献比例。
