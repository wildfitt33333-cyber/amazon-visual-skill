## 二、案例定位

这是一个针对美国市场 **30–60 岁生日消费人群**的高级视觉参考案例。

用于训练 Agent 判断：

- 成年生日场景如何区别于儿童生日。
- 如何通过家庭空间提升真实感。
- 如何利用低饱和色彩体现高级感。
- 如何让人物、产品、装饰形成合理视觉层级。

范围说明：30–60 岁为用户给出的参考适用人群，下一节的 40–60 岁女性为本案例更具体的创意定位。年龄范围不由照片推断，也不证明这类人群具有统一审美。

## 三、为什么优秀

本节为用户提供的优秀点与策略分析（E-BM003-02），可见表达参照 E-BM003-01；真实性、尺寸与市场偏好结论另行验证。

### 1. 用户年龄定位准确

目标用户：**40–60 岁女性生日消费者**。

视觉没有使用儿童化元素。

避免：

- 大量彩色气球。
- 卡通装饰。
- 过度夸张派对元素。

采用：

- 家庭客厅。
- 沙发空间。
- 朋友聚会。
- 葡萄酒。
- 简洁花艺。

用户判断：符合美国成年生日庆祝方式。

迁移限定：这些元素服务于本案例主题，不代表所有美国成年人或女性的偏好。照片中可见高脚杯和聚会表达，但无法鉴定饮品或人物关系；引用时称为用户指定的葡萄酒 / 朋友聚会情境，不作独立身份判断。

### 2. 色彩体系优秀

主要颜色：

- 莫兰迪橄榄绿。
- 奶油白。
- 米色。
- 木色。

特点：低饱和、高质感。让数字 50 成为视觉中心，同时保持家庭温馨感。

Agent 需要学习：成熟用户场景不要使用过度鲜艳颜色。

优先考虑：

- 自然色系。
- 高级中性色。
- 生活方式摄影感。

适用限定：上述为本案例的色彩路线，不是按年龄禁止鲜艳颜色的通用规则。用于后续项目时，先看用户主题、真实产品灯色和可比市场参考；不得改变产品外观或灯色来适配布景。

### 3. 产品视觉中心明确

数字 50：

- 位于画面核心区域。
- 尺寸比例真实。
- 灯光明显。
- 没有被装饰遮挡。

人物：

- 坐在产品旁边。
- 提供年龄和生活场景参考。
- 不抢产品视觉。

视觉排序：

1. 数字灯产品。
2. 人物情绪。
3. 背景氛围。

检查限定：人物提供活动语境，不能充当已标定的年龄或尺寸参照。真实比例需尺寸资料和合成 / 拍摄依据支持；当前画面中手部与 `5` 上缘接触，应在实际缩略图条件下检查是否干扰关键轮廓。

### 4. 人物真实感优秀

人物特点：

- 成年女性。
- 自然笑容。
- 放松坐姿。
- 真实家庭状态。

避免：

- 商业棚拍感。
- 过度摆拍。
- 不符合年龄的人物。

Agent 学习：人物应该作为场景真实性增强元素，而不是广告模特。

定位与自然感来自用户说明及视觉解读；具体年龄、实际家庭身份和是否摆拍未验证。“不符合年龄”在执行时应转化为符合用户明确角色设定，不依据外观判定真实年龄。

## 四、构图分析

空间结构：

| 层次 | 用户分析 |
| --- | --- |
| 前景 | 花艺、桌面、小装饰 |
| 中景 | 数字 50 + 人物 |
| 背景 | 家庭客厅 + 朋友交流 |

形成：**前景氛围 + 主体产品 + 真实生活背景**。

学习重点：使用空间层次增强高级感。

迁移时保持灯牌角色优先，前景花艺不遮字符；背景交流用于交代活动，不以更醒目的面孔或道具争夺产品注意力。气球虽配色克制但数量较多，仍需逐项目检查布景密度，不能理解为装饰越多越好。

## 五、光影分析

光线：自然窗光。

特点：

- 明亮柔和。
- 产品灯光与环境融合。
- 没有明显 AI 光效。

学习：Marquee 灯牌场景中，产品自身发光需要与环境光统一。

避免：

- 灯光漂浮。
- 黄色光污染。
- 不真实反射。

验证边界：可见明亮窗户与窗光风格，不证明仅使用自然光；没有明显 AI 光效是观感，不是图像来源鉴定。灯点与地面亮区不能证明真实亮度或照明性能。未来修改应保留实际灯色、字符轮廓、板体细节及合理接触阴影。

## 六、Agent 学习重点

用户提供的核心规则：

1. 成年生日灯牌需要匹配年龄消费群体。
2. 成熟生日场景优先：家庭空间 + 自然色彩 + 真实互动。
3. 产品永远是第一视觉中心。
4. 装饰服务产品，不允许装饰抢主体。
5. 人物应该体现生活状态，而不是摆拍展示。

执行条件：把年龄定位转化为实际购买者 / 庆祝对象的需求与主题，家庭空间和自然色彩是本参考路线，不是对所有成年生日的强制偏好。产品第一视觉与真实 SKU 保真优先，人物不得遮住关键字符或暗示错误比例。

## 八、禁止模仿

用户给出的本路线禁止项：

- 儿童生日风格。
- 高饱和气球堆叠。
- 过度商业摆拍。
- 人物抢产品视觉。
- 杂乱背景。

这些限制用于匹配本案例的成熟家庭生日创意方向，不禁止其他用户真实需要的鲜艳主题，也不代表年龄决定审美。借鉴方法而非复制人物、具体布景、图像内容或未经授权素材。
