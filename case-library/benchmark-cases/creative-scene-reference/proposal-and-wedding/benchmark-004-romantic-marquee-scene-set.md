## 二、案例定位

这是一个“浪漫仪式类灯牌场景参考组”，主要训练 Agent 理解：

1. 求婚场景与生日场景的区别。
2. 婚礼灯牌与生日灯牌在氛围表达上的区别。
3. 如何通过花艺、人物、动线、灯光和空间叙事构建高情绪价值的 Marquee 场景。
4. 什么样的构图更适合高客单、强情绪、强社交分享属性的灯牌产品。

组级创意定位：**高情绪价值 + 高仪式感 + 高社交传播感**，不是普通派对参考。

“高客单”和“社交传播”是目标定位与效果假设，未提供价格、传播或经营证据，不能认定产品实际客单价或已获得分享效果。

#### 核心特点

- 海边日落。
- 第一视角牵手构图。
- MARRY ME 字母灯作为仪式核心。

1. **情绪叙事极强**：不是单纯展示产品，而是展示“求婚这一刻”；用户想象被求婚或向他人求婚的场景。

#### Agent 学习重点

- 求婚类灯牌优先强调故事感，而不只展示大小。
- 第一视角是可探索的高价值创意方式。
- 花艺、蜡烛、步道可以形成叙事动线。
- 产品是仪式中心，人物是情绪入口。

## 四、为什么值得作为A级参考

用户给出的理由：

1. 覆盖三类浪漫仪式核心场景：求婚、户外婚礼、室内婚礼晚宴。
2. 不只是摆放产品，而是构建完整事件感。
3. 三个场景都追求人物真实、场景真实、产品清晰、氛围高级和社交传播潜力。
4. 帮助 Agent 区分 **生日灯牌场景 ≠ 求婚灯牌场景 ≠ 婚礼灯牌场景**。

A级参考学习的是事件与视觉逻辑；上述质量判断保留为用户分析，待三图复核，不提前认定全部达标。

## 五、Agent 学习重点（统一沉淀）

1. 浪漫仪式类灯牌核心是情绪与记忆，而不只是热闹。
2. 求婚场景优先：**故事感 + 动线 + 沉浸感 + 第一视角代入**。
3. 婚礼场景优先：**专属表达 + 优雅花艺 + 真实新人互动 + 场地氛围**；“专属定制”仍需实际服务支持。
4. 产品必须清晰可识别，不机械追求生日展示中的绝对大占比；与事件叙事融合，但不能沦为不可辨的背景道具。
5. 可探索的高情绪价值构图：背影、牵手、对视、共舞、通道、花艺框景。

共同视觉语言：人物作为情绪入口，动线引导到产品，装饰提供仪式语境，空间体现事件阶段。差异保留：A 的第一视角、B 的身份符号、C 的室内舞会，以及各自实际灯色与高度。

这些是组内创意方向，不是所有求婚 / 婚礼买家的强制偏好；80/20 策略仍需可比市场样本，不用单组代替市场共识。图中花艺、烛光、串灯等不能被表达为随附物品。

## 七、适用决策：什么时候调用本案例组

如果任务符合以下任一条件，优先考虑本组作为条件参考：

- 产品主题为 MARRY ME / LOVE / J&R / 婚礼首字母。
- 目标为求婚、婚礼、婚礼晚宴或相关浪漫纪念场景。
- 需要高情绪价值场景。

## 八、禁止模仿

- 把求婚场景做成普通生日派对。

- 人物动作僵硬摆拍。
- 灯光与环境色温冲突。
