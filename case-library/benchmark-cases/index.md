## 2. 每个案例的调用条件与不适用情况

### BM-001：字母 A 生日儿童场景

**优先调用**：产品是字母灯牌，任务是儿童家庭生日场景，需产品第一视觉、人物辅助情绪和暖光生活感。A / 4FT 接近时可作为较强参考，但必须锁定当前实际字符与尺寸。

**可迁移部分**：单字母层级、人物与产品平衡、家庭背景。迁移到其他字母或 Teen 场景须说明差异，不能照搬人物、年龄、主题或产品比例。

**不适用 / 不可直接迁移**：数字年龄表达、求婚或婚礼完整叙事、成年人中性色偏好证明、4FT 尺寸认证、纯白合规主图范本。儿童生日数字项目最多借鉴层级，不把它作为数字类型主参考。

### BM-002：数字 16 Teen 生日场景

**优先调用**：数字灯牌 + 明确 Teen 生日 + 生活场景副图，需年龄数字识别、自然人物互动和派对空间表达。

**年龄匹配**：16 岁是核心输入主题；15、18 岁是原案例允许的条件迁移方向，须用户确认实际年龄与对应 SKU。年龄标签不能自动决定配色、人物性别或购买心理。

**可迁移部分**：坐姿降低展示感、气球形成框景、产品与人物空间关系。另核对人物腿部与数字局部重叠及布景密度，不默认原图无任何遮挡。

**不适用 / 不可直接迁移**：字母类产品主参考、婚礼或求婚仪式、未知年龄自动设为 16、不同年龄机械使用黑白金、高度或亮度认证、搜索 CTR 成功证明。

### BM-003：数字 50 Adult 家庭场景

**优先调用**：数字灯牌 + 成年生日 + 家庭客厅 / 朋友庆祝，明确需要生活方式摄影、低饱和自然色与人物 / 产品并列。

**年龄匹配**：30–60 岁为参考适用范围，40–60 岁女性为原始核心定位；50 是案例活动数字，不是从人物外观推断的年龄。其他成人任务可条件迁移，男性或其他角色不因性别自动排除构图方法。

**可迁移部分**：家庭空间层次、中性色路线、人物生活状态、产品与背景分工。40%–50% 占比未定义测量口径，不作为匹配阈值。

**不适用 / 不可直接迁移**：儿童生日主参考、婚礼完整叙事、所有成人都偏好低饱和的结论、强行加入饮酒元素、合规主图范本、按年龄禁止鲜艳主题。

### BM-004：浪漫仪式场景参考组

**优先调用**：字母灯牌 + 求婚 / 婚礼 / 婚礼晚宴，或已确认的浪漫纪念场景，需动线、事件感、专属表达或高情绪价值创意。

年龄不设匹配区间，以事件角色和任务为依据。不能因为用户为 Adult 就自动选婚礼，也不能因为姓名首字母就推断其关系身份。

## 4. Agent 匹配与调用顺序

### 4.1 统一输入

整理 `marketplace`、`material_status`、`product_type`、`characters`、`sold_quantity`、`height`、`light_color`、`occasion`、`event_stage`、`age_if_provided`、`audience_roles`、`theme`、`image_role`、`visual_goal` 和 `environment_constraints`。

缺失值保留未知；不从照片推断年龄，不把数字自动当人物实际年龄。产品型号、尺寸与活动用途不能从案例反向填入项目。

### 4.2 先过滤，再比较

1. **范围过滤**：仅美国站 KT 板灯牌；明确不符则不匹配。材质未知可整理候选，但标记范围待确认。
2. **角色过滤**：纯白主图、规格或包装任务不能以生活场景当完整制作范本；仅可借鉴不冲突的主体识别原则，平台要求另核实。
3. **主题路由**：明确活动和事件阶段优先，按第 3 节选择；年龄不能把求婚路由到生日。
4. **产品匹配**：同数字 / 字母与售卖组合优先；跨类型只允许拆分方法借鉴，不改变本品身份。
5. **人群与主题匹配**：依据输入年龄 / 角色与实际主题比较，不用性别或年龄刻板偏好替代需求。
6. **事实约束检查**：尺寸、灯色、结构、数量、室内外条件不同则记录差异，禁止迁移不成立的功能或场景。
7. **可用性检查**：打开选定案例全文，读取最新验证状态；索引不替代原文。无可访问原图时仅引用已有观察或文本，不能声称本次重看图片。

### 4.3 排序、冲突与无匹配

- 路线按“活动任务 → 产品类型 → 人群与主题 → 真实尺寸 / 灯色 / 环境 → 素材可用性”判断，不用未经验证的相似度分数。
- 用户明确的当前任务与产品事实优先于标签；A级不会压过不匹配的活动或产品。
- 通常选择一个主参考，其余仅作明确维度的补充；BM-004 可按事件阶段选多个子图，但仍只是一组。
- 匹配结果区分：`primary` 主参考、`conditional` 有关键待确认项、`technique_only` 方法借鉴、`excluded` 不适用。没有合适案例允许 `no_match`。
- 已知类型 / 活动冲突不能仅因颜色接近晋升主参考；合理主题变更后重新路由。
- 多个候选接近时说明差异；缺失信息若决定路线，提出必要待确认项，继续不依赖答案的诊断。

## 6. 共通限制与维护

- 四个案例都未提供 CTR / CVR 实测成功依据；参考不能证明销量、美国市场共识或预期提升幅度。
- 所有原图当前只在对话中提供，仓库没有持久化图片二进制。BM-001–003 各有一图观察，BM-004 三图均已查看；新的任务若无法访问原图，不声称已完成实时视觉复核。
- BM-001 / BM-003 的“主图”是用户原始用途，合规待核实；BM-002 / BM-004 的场景用途同样需按实际位置核实规则。
- 不迁移年龄、人物身份、饮品、主题色、灯色或尺寸作为当前项目事实；不以场景图认证安全、定制、户外、性能或完整套装。
- 本索引不改变既有案例内容或等级。未来增补案例或验证资料后同步索引；长期规则仅经独立复核更新，不因案例入库自动改写。
