# Creative Reference Group 创意参考组模板

本模板用于未来记录具有高级视觉表达价值的商业图片参考组，当前不含具体案例。适用范围仅为 Amazon US KT 板数字 / 字母灯牌及相关活动场景；环境道具不成为其他产品类别。

**Benchmark Case** 用于匹配具体产品、人群和场景。**Creative Reference Group** 用于学习视觉方法、构图策略与情绪表达；方法可迁移，但不代表参考产品与当前 SKU 完全匹配。不移动、替换或重新编号现有 Benchmark，也不复制原图内容。

## 3. 为什么有效

### 3.1 为什么画面具有高级感

- 支持判断的具体证据：克制配色、空间秩序、主体分离、材质细节、自然动作或光影协调：
- 这些方法如何服务灯牌识别与事件表达：
- 目标受众和图片角色的适用条件：
- 限制、相反证据或审美分歧：

“高级感”为视觉评价，不能等同于昂贵布景、美国市场共识或平台官方评级。

- 是否帮助理解实际产品、真实使用效果、生日 / 婚礼 / 求婚事件或纪念价值：
- 是否减轻尺寸、布置、材质或场景适配顾虑，依据是什么：

### 不能复制

- ✗ **人物**：不复制原人物面貌、身份或具体动作；独立设计当前任务角色。
- ✗ **装饰**：不照搬原花艺、气球、家具及组合布置；同类元素按真实任务重新选择与安排。
- ✗ **文案**：不复制姓名、日期、年龄、标语、Logo 或品牌内容；按事实与图片位置决定独立文案。
- ✗ **具体场景**：不复刻原场地、布局或图像内容；可以学习家庭 / 仪式空间的组织方法，需独立设计地点与环境。

产品比例也不能复制：以当前 SKU 尺寸、人物资料和透视重算，保留本品字符、板材、支撑及灯色。方法借鉴不等于取得图片、人物或场地素材使用权。
