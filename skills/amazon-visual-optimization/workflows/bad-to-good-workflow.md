# 旧 Listing 差转优工作流

入口：[SKILL.md](../SKILL.md)。交付使用 [差转优报告模板](../templates/bad-to-good-report-template.md)。

```text
当前图片与输入整理
→ 问题分析
→ TOP 竞品差距（TOP 未确认时按参考分析）
→ 市场验证（样本和证据验证）
→ 差异化判断
→ 优先级与优化方案
→ AI 编辑 / 重做 Prompt
→ 验收标准与后续实验计划
```

| 环节 | 操作 | 必须产物 |
| --- | --- | --- |
| 输入 | 查看当前图、参考图，确认产品事实与反馈来源 | 图片清单、事实、缺失项 |
| 问题分析 / Step 1 | 逐图检查，再查组图顺序与覆盖 | 问题 ID、区域证据、原因假设 |
| 竞品差距 / Step 2 | 独立观察参考，按相同角色对比 | 差距表、参考依据和适用边界 |
| 市场验证 / Step 2 | 去重、分层、统计模式，验证 TOP / 销量依据 | 样本范围、购买信号、局限 |
| 差异化 / Step 3 | 分离硬约束、市场共识和突破机会 | 路线、保留项、突破项、风险 |
| 排序 / Step 4 | P0 / P1 / P2 排序，考虑成本依赖 | 可执行任务队列 |
| 方案 / Step 5 | 选择编辑、重拍或重做，给出具体调整 | 逐图方案与验收条件 |
| Prompt / Step 6 | 引用源图、保真约束与策略 | 逐任务英文 Prompt、中文摘要 |
| 验收 / Step 7 | 分开检查方案、改图和真实表现 | 状态表与实验计划 |

## 缺失和异常处理

- 缺当前图：不能逐图诊断，先整理产品与参考，列出阻塞项。
- 缺参考：当前图诊断继续，差距和市场判断标记未完成；不要用想象竞品代替。
- 单张参考或样本不匹配：只作局部借鉴，不宣布市场趋势。
- 产品事实与画面冲突：优先核实、纠错；不能复制竞品事实。
- 用户称“低转化”但无数据：记录为用户陈述，不推断根因或提升幅度。
- 已有反馈：按版本、窗口和来源整理；前后对比与随机实验分开，不把 CTR 上升自动当作成功。

## 交付门槛

当前问题、参考差距、优先级、修改方案、AI Prompt 五项全部保留；同时给出原因链、市场策略和验收。受阻部分写明缺失材料，完成可做部分，不以“已差转优”描述尚未制作或未验证的结果。
