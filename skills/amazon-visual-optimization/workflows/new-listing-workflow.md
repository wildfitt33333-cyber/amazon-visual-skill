# 新品 Listing 视觉规划工作流

入口：[SKILL.md](../SKILL.md)。交付使用 [新品报告模板](../templates/new-listing-report-template.md)。

```text
产品信息与真实素材
→ 产品分析 / 素材诊断
→ 用户画像与购买顾虑
→ 竞品与市场信号
→ 主流 / 差异化策略
→ 场景与图片结构
→ 制作优先级和逐图 Brief
→ AI Prompt
→ 验收标准
```

| 环节 | 七步对应 | 必须产物 |
| --- | --- | --- |
| 产品分析 | Step 1 | 已确认事实、卖点依据、素材问题、待补信息 |
| 用户画像 | Step 1 的规划扩展 | 使用任务、动机、顾虑、假设与来源 |
| 市场判断 | Step 2 | 参考样本、共同模式、购买信号及限制 |
| 策略决策 | Step 3 | 共识 / 突破矩阵、路线和验证假设 |
| 场景与结构 | Step 3 → Step 5 | 场景库、图片任务与顺序、信息覆盖 |
| 制作排序 | Step 4 | 关键素材与图片制作任务的优先级和依赖 |
| 逐图 Brief | Step 5 | 目标、主要信息、构图、比例、光影、素材、文案 |
| Prompt | Step 6 | 生成 / 合成模式、真实产品引用、保真约束 |
| 验收 | Step 7 | 方案检查、成图检查和未来业务验证 |

## 新品专属要求

- 没有旧图时，不输出虚构的低转化问题或前后表现。
- 用户画像基于使用任务，假设明确标注；不凭外观断言人物身份。
- 场景说明人物、地点、行为、产品价值，主图不强行加入生活背景。
- 图片数量根据品类与购买信息确定，不机械固定七图。
- 每张图围绕一个主要购买问题，英文文案只使用已确认卖点。
- 新品无历史数据可先交付方案；市场资料不足时标记条件策略。
- 产品形状、颜色、接口、尺寸和包装等关键资料不足时，对应 Prompt 为草案或受阻，优先补素材。

## 交付门槛

包含产品分析、用户画像、场景策划、图片结构、制作 Brief 和 AI Prompt；每图关联事实与策略，提供实际成图的验收标准。不得将规划完成等同 Listing 已发布或效果已验证。
